## [Unreleased]

### 🎨 Brand

- **Diamond CodeShot identity**: refined the official rounded capture-frame mark with a centered diamond code signature, improved capture corners, and the premium `#6D28D9 → #7C3AED → #8B5CF6 → #C084FC` gradient.
- **Complete brand asset system**: added primary, vertical, transparent, dark, light, monochrome, favicon, sprite, and Marketplace SVG variants under `brand/`, plus reproducible Chrome, VS Code, favicon, and desktop PNG exports generated by `brand/generate_assets.py`.
- **Three-app integration**: the web app and Chrome extension now load the official SVG in their header and onboarding; the VS Code webview replaces the camera emoji with the same official mark, while the Activity Bar and marketplace icon use refined assets.
- **Compact themed wordmarks**: reduced the dark/light logo panels to content-fit width and centered their icon vertically.

### 📦 Distribution

- **Release 1.3.1**: synchronized Chrome and VS Code manifest versions and regenerated both distribution packages from the refined source assets.

### ⚙️ CI/CD

- **Automatic GitHub Pages deployment** (`.github/workflows/deploy-pages.yml`): push to `main` now automatically deploys `codeshot-web/` to the `gh-pages` branch using `JamesIves/github-pages-deploy-action`. The workflow only triggers when files inside `codeshot-web/**` change; existing files in `gh-pages` not present in `codeshot-web/` (e.g. `vendor/`) are preserved (`clean: false`). Manual dispatch via `workflow_dispatch` is also supported.

### 🐛 Fixed

- **Custom selection menus**: when a `select-shell` is open, its accordion panel no longer clips the option list, keeping the final option visible and accessible.
- **Prism Funky and Coy themes**: removed Prism's built-in code-card backgrounds, patterns, shadows, and decorations that overlapped the editor surface while preserving each theme's syntax highlighting palette.
- **SonarQube — CSS `!important` rules**: the Funky and Coy theme overrides no longer require `!important`; precedence is resolved through stylesheet load order and selector specificity.

## [1.3.0] - 2026-10-27

### ✨ Added

- **Curated template filters**: the template gallery now filters by style/destination (Professional, Documentation, Social) and vertical ratio, retaining `aria-pressed` states for accessible navigation.
- **Batch code-file processing** (web/Chrome app): select up to 12 snippets/files, detect their language from the extension, and generate a PNG 2× ZIP using the active visual composition. The queue runs sequentially, reports progress, and restores the original editor state afterward.
- **Destination export packs** (web/Chrome app): LinkedIn, Documentation, and Social now generate ZIPs with their real format/scale combinations. File names are deterministic, and WEBP uses a PNG fallback suffix when unsupported.
- **Actionable export feedback** (web/Chrome app): displays visible generating, preparing, and success states; if an export fails, it provides a contextual explanation (missing renderer, security restriction, or rendering failure) plus an accessible retry action.
- **Font warning in the export preflight** (web/Chrome app): uses the Font Loading API to check whether the selected font family is available; when it is not, the preflight explains that the exported image will use a fallback font. The warning refreshes when the font changes.
- **Persistent project library upgrades** (web/Chrome app):
  - Real JPEG thumbnails generated from the current canvas and stored with each project.
  - Versioned IndexedDB database (`codeshot-library`) for projects, with automatic migration from the existing `localStorage` library.
  - Resilient `localStorage` cache/fallback retained for immediate startup and environments where IndexedDB is unavailable.
  - Automatic reconciliation of IndexedDB and cached projects by project ID and `updatedAt`, preserving the latest copy.
  - Project backup/import, autosave, versions, rename, duplication, archive/restore, and deletion now use the same persistence layer.
  - Resetting defaults also removes the versioned local project database.

### 📚 Documentation

- Documented the persistent project library, real thumbnails, JSON backup/import, and IndexedDB storage strategy in both English and Spanish READMEs.

### 🔄 Changed

- **Extension version** bumped to `1.3.0`.

### 🐛 Fixed

- **SonarQube — `role="status"` in HTML**: the `<div role="status">` on the export feedback banner (`#exportFeedback`) replaced by the native `<output>` element, which provides status semantics without an explicit role.
- **SonarQube — `role="group"` in HTML (×2)**: both `<div role="group">` elements replaced by `<fieldset>` with `<legend class="sr-only">` — the project library filter toolbar and the template gallery filter bar.
- **SonarQube — unlabelled file input**: added `<label for="importProjectsInput" class="sr-only">` to the hidden JSON project-import field.
- **SonarQube — unhandled promise**: `autosaveActiveProject(true)` in `saveActiveProjectNow()` explicitly marked with `void`.
- **SonarQube — nested ternary in `renderProjects`**: three-branch ternary extracted to an explicit `if/else if/else` block assigning the `emptyMessage` variable.
- **SonarQube — nested template literal in `renderProjects`**: the conditional template literal inside `item.innerHTML` decomposed into pre-computed variables (`restoreVersionBtn`, `archiveLabel`, `archiveIcon`, `activeLabel`).
- **SonarQube — nested ternary in `updateBatchFilesStatus`**: pluralisation ternaries extracted to independent variables `fileLabel` and `readyLabel`.
- **SonarQube — `await` inside loops (×2)**: both `for...of` loops with `await` (batch export and pack export) refactored to `Promise.all` with `.map()`.
- **SonarQube — Cognitive Complexity in `exportPackBtn`**: reduced from 17 to ≤ 15 by extracting the per-file build logic into the `generatePackFile(base, pack, definition, index)` function.
- **SonarQube — `.then()` chain / async IIFE at startup**: `void hydrateProjectsFromDatabase().then(...)` and the subsequent async IIFE replaced by the named `async startApp()` function invoked with `void startApp()`.

### 🗺️ Planned

- Publish the extension on the VS Code Marketplace.

## [1.2.0] - 2026-10-22

### ✨ Added

- **Social media sharing dropdown** (web version): the "🔗 Share" button now opens a dropdown with:
  - **"Share image"** button — uses the Web Share API (`navigator.share({ files: [...] })`) to open the OS native share sheet (WhatsApp, Instagram, Telegram, etc.) on mobile; falls back to downloading the image on desktop.
  - **"Copy link"** button — copies the serialized state URL to the clipboard (same as before).
  - **Social network buttons** with official SVG icons: **X / Twitter**, **WhatsApp**, **LinkedIn**, **Reddit**, **Facebook** — open the respective share dialog in a popup window with the state URL.
- **Style presets** in the VS Code extension: the sidebar now includes a "Style presets" section identical to the web version — save the current visual configuration (language, theme, font, frame, background, etc.) with a custom name and restore it with one click; persisted in `localStorage`.

### 🔄 Changed

- **Improved scrollbar design** (web + VS Code): all scrollable elements now use a consistent, polished scrollbar — 6 px slim with rounded thumb, floating effect (`background-clip: content-box`), accent color on hover, and Firefox support (`scrollbar-width: thin`). Applies to: controls panel, history list, preview area.
- **Fixed textarea scrollbar**: `overflow: hidden` added to `.code-input` and `overflow: visible` removed from the shared `pre, textarea` rule, eliminating the unexpected scrollbar that appeared in the code editor area.
- **Extension version** bumped to `1.2.0`.

### 🐛 Fixed

- **SonarQube — duplicate selector**: `scrollbar-width`/`scrollbar-color` (Firefox) merged into the main `.controls-panel` block to eliminate the duplicate selector warning in both `codeshot-web/style.css` and `codeshot-vscode/media/style.css`.
- **SonarQube — Cognitive Complexity**: `applyPresetState` in the VS Code extension refactored from CC 48 to CC ≤ 15 by decomposing into `applyPresetEditorStateVSC`, `applyPresetFrameStateVSC`, `applyPresetAppearanceVSC` (with sub-functions `applyPresetPaddingVSC`, `applyPresetRadiusVSC`, `applyPresetShadowVSC`), and `applyPresetBgStateVSC`.
- **SonarQube — Cognitive Complexity**: `shareImageBtn` click handler refactored from CC 18 to CC ≤ 15 by extracting `handleShareImageBlob(blob, filename)`.
- **SonarQube — optional chaining**: `navigator.canShare && navigator.canShare(...)` replaced with `navigator.canShare?.()`.

## [1.1.0] - 2026-10-22

### ✨ Added

- **Local history of generated screenshots** (web version): the last 8 exported images are saved in `localStorage` as thumbnails; each entry can be re-downloaded with one click. The history is cleared with the "Clear history" button.
- **Multi-resolution ZIP export** (web version): the "Export ZIP" button generates a `.zip` file containing three PNG files at 1×, 2×, and 3× scales simultaneously, built with a pure-JS ZIP implementation (no external libraries).
- **"Copy image" button** in the header: copies the screenshot directly to the clipboard using the `ClipboardItem` API, without downloading the file.
- **Font family selector**: Fira Code, JetBrains Mono, Cascadia Code, Source Code Pro, Consolas.
- **Frame width control** (slider 400–1400 px): allows creating wider screenshots for code with long lines.
- **Configurable starting line number**: useful when capturing a fragment from a real file (e.g. lines 120–145).
- **Editable watermark text**: no longer hardcoded to "Made with CodeShot".
- **Auto-adaptive watermark color**: automatically switches to dark color when the active background is light.
- **Live line and character counter** (e.g. `47 lines · 1.2 KB`).
- **Per-language code templates**: 18 representative snippets — each language shows its own idiomatic example instead of the same `fibonacci` for all.
- **Automatic language detection on paste**: heuristics on the first line of code detect Python, Rust, PHP, Go, C++, Java, C#, JSX, SQL, YAML, JSON, Bash, HTML, and Markdown.
- **File drag & drop**: drag any code file (`.js`, `.py`, `.rs`, etc.) onto the editor to load it; language and window title are updated automatically.
- **"Restore defaults" button**: clears all `localStorage` preferences and reloads the interface.
- **UI keyboard shortcuts**: `Ctrl+Enter` downloads, `Ctrl+Shift+C` copies to clipboard, `Ctrl+L` clears the code, `Ctrl+±` controls zoom.
- **Complete preference persistence**: language, code theme, font size and family, frame style and width, title bar, line numbers, starting line, padding, radius, shadow, watermark, and background are saved in `localStorage` and restored on reload.
- **New VS Code command `codeshot.captureFile`**: captures the entire open file without needing a text selection.
- **Explicit `activationEvents`** in `package.json` for all three commands and the sidebar view.
- **VS Code keybindings**: `Ctrl+Shift+S` → capture selection; `Ctrl+Shift+Alt+S` → capture full file.
- **Improved Marketplace categories**: added `Snippets` and `Education`.
- **`retainContextWhenHidden: true`** on the Activity Bar view: webview state is preserved when the panel is hidden.
- **JPEG export** with a quality slider (50–100 %): new "Export" section in the controls panel; transparent backgrounds are automatically replaced with white when exporting as JPEG.
- **Configurable export scale** (1×, 2×, or 3×): replaces the previously fixed 2× scale.
- **Named style presets** (web version): save the current visual configuration (language, theme, font, frame, background, etc.) with a custom name and restore it with one click; presets are persisted in `localStorage`.
- **Share by link** (web version): the "🔗 Share" button serializes the full state (settings + code) into the URL hash using Base64; opening that link automatically restores the complete state.

### 🔄 Changed

- **Critical bug fixed — long-line resizing**: the window frame now auto-expands with content instead of clipping it. Changes: `window-frame` uses `min-width` instead of a fixed `width`, `max-width: 100%` removed from `export-stage`, `code-editor-wrapper` changed to `overflow: visible`, `#highlightPre` uses `width: max-content`, and `syncTextareaSize()` syncs both height and width of the textarea overlay.
- **Improved performance**: 80 ms debounce on `highlightCodeNow` (avoids re-running Prism on every keystroke), incremental `updateLineNumbers` (only recalculates when the line count changes), `syncTextareaSize` uses `requestAnimationFrame` (avoids forced synchronous layouts).
- **`mapVscodeLanguageToPrism` expanded**: added Kotlin, Swift, Dart, Scala, Lua, PowerShell, R, Groovy, Perl, Dockerfile, TOML, INI, Batch, Objective-C, CoffeeScript, GraphQL, Handlebars, Less, SCSS.
- **"Actions" section** added to the controls panel with a summary of available keyboard shortcuts.
- **Extension version** bumped to `1.1.0`.

### 🐛 Fixed

- **`pendingSelection` as a global variable**: replaced with a `Map<Webview, Selection>` to prevent race conditions when the panel and the sidebar view are open simultaneously.

## [1.0.0] - 2026-10-11

### ✨ Added

- **Initial web app**: visual code-screenshot editor (`index.html`, `style.css`, `script.js`) with:
  - Live syntax highlighting with Prism.js (18+ languages, 9 color themes).
  - Window frames: macOS, Windows, Browser, Ubuntu/Linux, and "no frame".
  - Predefined gradient backgrounds or custom color.
  - Appearance controls: padding, border radius, shadow intensity, line numbers, watermark.
  - Light/dark UI theme, persisted in `localStorage`.
  - High-resolution PNG export (2x) with `html2canvas`, including real transparency support.
  - Accessibility: keyboard navigation, ARIA roles, WCAG 2.2-compliant contrast.
- **Chrome extension (Manifest V3)**:
  - `manifest.json`, `background.js` (service worker) to open/focus the app in a new tab.
  - Local vendoring of Prism.js and html2canvas (no CDNs) to comply with Manifest V3's Content Security Policy.
  - Extension icons at 16/32/48/128px with a custom design (camera + `</>` symbol).
- **VS Code extension**:
  - `extension.js` with `WebviewPanel` logic, two commands (`Open screenshot editor`, `Capture current selection`), and a message bridge (`postMessage`) with the webview to save images via the native "Save As" dialog.
  - Automatic language and file name detection when capturing a selection from the active editor.
  - Its own `package.json`, `README.md`, and `.vscodeignore`.
- Ready-to-install distribution packages: `extension/codeshot-chrome-extension.zip` and `extension/codeshot-vscode-extension.vsix`.
- Main `README.md` documenting the three variants of the project (web app, Chrome extension, VS Code extension), with installation instructions, project structure, tech stack, and roadmap.

### 🔄 Changed

- **Full rebranding** from "CodeSnap Clone" to **CodeShot**: title, visual identity, `localStorage` keys, exported file names, VS Code command names (`codeshot.*`), `manifest.json`, and `package.json`.
- **Favicon and extension icon** redesigned: a camera with the `</>` code symbol in the lens, over a purple gradient background consistent with the brand palette.
- **"Windows" frame** redesigned: app icon, minimize/maximize/close controls drawn entirely in pure CSS (no Unicode glyphs).
- **"Browser" frame** improved:
  - Tab favicon, navigation arrows, and refresh icon drawn in pure CSS.
  - Added window controls (minimize/maximize/close) in the top-right corner of the bar, matching the look of a real desktop browser.
  - Security lock icon rebuilt as an independent `.lock-icon` element with its own positioning context, fixing the broken overlap with the original 🔒 emoji.
- **"Ubuntu/Linux" frame** redesigned: GNOME/Yaru-style circular controls, with subtle glyphs visible only on hover and the characteristic Ubuntu orange.

### 🐛 Fixed

- Removed the duplicated 🔒 emoji in the browser frame's URL bar (it rendered as a broken square due to missing emoji fonts in some environments); replaced with an icon drawn entirely in CSS.
- Fixed the browser frame's refresh icon, which wasn't recognizable as such; redesigned using the "rotated circle with a gap + arrow tip" technique.
- Fixed SonarQube warnings in the VS Code extension: using `node:fs`/`node:path` instead of `fs`/`path`, `String#replaceAll()` instead of global-regex `replace()`, a non-empty `deactivate()` body, and origin verification (`event.source === window`) in the webview's `postMessage` listener.
